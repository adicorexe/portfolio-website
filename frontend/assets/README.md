# Assets Folder

Replace these placeholders with your real files before deploying:

- `resume.pdf` — Add your actual resume PDF here (referenced by the "Download Resume" buttons).
- `images/` — Add your profile photo, project screenshots, and `og-image.jpg` (used for social sharing previews) here.
- `icons/` — Add your `favicon.png` (recommended size 512x512) here.

The site currently uses icon-based placeholders (via Font Awesome) instead of real images/photos so it runs out of the box with zero missing-file errors. Swap in real `<img>` tags once you have your assets ready.
